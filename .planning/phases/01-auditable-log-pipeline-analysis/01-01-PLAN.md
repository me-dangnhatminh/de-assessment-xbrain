| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-SC | Tampering | uv/PyPI package bootstrap and installs | high | mitigate | Blocking human legitimacy gate verifies all SUS package identities before bootstrap/install; `uv.lock` pins the approved resolution. |
| T-01-01 | Tampering | `pipeline/__main__.py` output-root handling | high | mitigate | Resolve paths before writes, reject any generated root within `docs/onboard`, and test the rejection before creating files. |
| T-01-02 | Denial of Service | JSONL line parsing | medium | mitigate | Stream only the selected line in the tracer and enforce the documented 1 MiB maximum before JSON parsing. |
| T-01-03 | Repudiation | tracer evidence | medium | mitigate | Record source path, source line, pre/post SHA-256, output hashes, row counts, SQL path, and command metadata in the tracer manifest. |
