| Generated Parquet/ledger → DuckDB SQL | Evidence files are trusted only after schema/hash/conservation verification. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-10 | Tampering | `pipeline/analysis.py` SQL execution | high | mitigate | Load only checked-in static SQL and bind Parquet/ledger paths as parameters; never concatenate caller input into query text. |
| T-01-11 | Repudiation | customer-answer tables | medium | mitigate | Fixed query IDs, SQL paths, result paths, schemas, deterministic ordering, and reconciliation tests preserve how each answer was produced. |
