<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| `docs/onboard/datapack/data/docs/` → kb pipeline | Supplied Markdown files are untrusted, immutable inputs read by the inventory/chunking pipeline. |
| User search query → SQLite FTS5 | User-supplied query text enters FTS5 MATCH — must use parameter binding. |
| kb output directory → filesystem | Generated index.sqlite and chunks.jsonl must not overwrite source documents. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Injection | `kb/search.py` FTS5 query | high | mitigate | All FTS5 queries use `?` parameter binding; no string interpolation or f-string SQL construction. |
| T-02-02 | Tampering | Source document integrity | high | mitigate | Inventory records SHA-256 of each source document; search results include source_path for traceability. The docs directory is never written to. |
| T-02-03 | Denial of Service | Malformed Markdown parsing | low | accept | The 8 documents are known, small, and structurally simple. The chunker handles missing ## sections gracefully (single-chunk fallback). |
| T-02-04 | Repudiation | KB version resolution | medium | mitigate | The is_current computation is deterministic and logged in chunks.jsonl; the supersession phrase detection is testable. |
</threat_model>
